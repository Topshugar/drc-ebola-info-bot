# DRC Ebola USSD Bot 🇨🇩

> Offline-first life-saving info for eastern Congo. Works on any phone, no internet.

**Current crisis:** 4,018+ deaths, 8,300+ cases, worst DRC outbreak ever. Kigonze transit center burned, 19k displaced.

## What it does
- USSD *XXX# menu: Symptoms, Prevention, Nearest Center, Emergency 109
- Languages: FR, SW, LN
- SMS fallback

## Quick start
pip install -r requirements.txt
python app.py

## Deploy
1. AfricasTalking account
2. Set callback to /ussd
3. Deploy to Render

WHO AFRO, UNICEF, OCHA - data refreshed daily
